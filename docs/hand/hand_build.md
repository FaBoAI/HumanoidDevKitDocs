# 手首の組立

## 1.RS05と土台の接続

![](./img/hand001_parts.png)

H001とH002をH009(M3x8mm皿ねじ)のネジで固定する。

![](./img/hand001.png)

## 2.rotor armにベアリングをはめる

![](./img/hand002_parts.png)

H005にH110のベアリングをはめる。きついので金槌等で押し込むと良い。

![](./img/hand002.png)

## 3.rotor armをrotorに固定

![](./img/hand003_parts.png)

H004に、H106(M3x10mm), H107(M3ワッシャー), H108(M3ナット)で固定する。

![](./img/hand003.png)

![](./img/hand003_002.png)

## 4.rotorをRS05に固定

![](./img/hand004_parts.png)

rotorをRS05に、H102(M4x10mm)のねじ 2個でしっかり固定する。

![](./img/hand004.png)

## 5.Linearレース取り付け

![](./img/hand005_parts.png)

Linearレースを取り付ける。H111の六角ナットをH003の裏面に差し込む。きついので金槌等で押し込むと良い。表面にLinearレールを取り付けて、H112のM2x20mmのネジでしっかり固定する

![](./img/hand005.png)

![](./img/hand005_002.png)

![](./img/hand005_003.png)

## 6.Fingerの留め具をとつける

![](./img/hand006_parts.png)

H115のM2x6mmのネジで、H006をLinear laceに取り付ける。

![](./img/hand006.png)

左側がねじ止めできたら、右側も取り付ける。

![](./img/hand006_002.png)

![](./img/hand006_003.png)

## 7.Fingerの留め具とrotorを連結

![](./img/hand007_parts.png)

Fingerの留め具の裏側にある穴に、routor armの穴からH105のM3x14mmのネジを使って連結する

![](./img/hand007.png)

![](./img/hand007_002.png)

## 8.ベースとLinearの連結

![](./img/hand008_parts.png)

ベースとLinearをH103のM3x20mm六角ネジと, H104のナットで固定する。

![](./img/hand008.png)

![](./img/hand008_002.png)

## 9.fingerの取り付け

![](./img/hand009_parts.png)

Fingerの左右を、最後のネジのH113 M2x20mm六角ねじ, H114のナットで取り付ける。
![](./img/hand009.png)

![](./img/hand009_002.png)

![](./img/hand009_003.png)
